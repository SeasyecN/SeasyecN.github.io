# Sore，从王者到坟墓
 
 2024年2月15日， OpenAI 毫无预兆地发布了 Sora。相比当时行业内普遍只能生成 3-4 秒、充满扭曲和畸变的 AI 视频模型，Sora 直接抛出了长达 60秒、一镜到底、且具备多角度镜头切换和极高物理真实感的高清视频。

 sora在当时轰动了全世界，引发了人们对AI视频生成技术的极大兴趣和热议。许多专家和爱好者纷纷尝试使用Sora，探索其在创意、娱乐、教育等领域的潜力。老大，海岛奇兵的视频层出不穷给我带来了无限的乐趣。

 后面sora开始饥饿营销，只开发给网红，漏洞测试人员，艺术家。这导致了被voe模型抢占先机，从而导致sora热度下降

 2025年9月30，正式开始公测，并于同年12月开始商业化

2026年3月24日， OpenAI 突然宣布全面关停 Sora 的消费者端服务和 API 接口。历史在此刻画上句号。团队被重组去做“世界模拟”和机器人技术，Openai视频生成的 C 端美梦宣告结束。

# Goodbye Sore，Hello Seedance2

Sora的结束并不是c端视频的终结，Seedance2 是目前视频生成领域不可忽视的存在。抖音有大量的视频生成出我看不出的是AI生成的视频，还有一些用seedance2生成的电影，完全看不出来是ai生成的。但其实大部分视频都是工作室做的，Sora死在了c端的，而seedance2活在了b端。
我觉得人们很容易轻易的迷失在短视频的泡沫中，Sora的用户流失率太快了，显而易见没有多少用户可以用sora建立稳定的工作流。
